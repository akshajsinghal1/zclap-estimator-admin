Key assumptions

Changes to assumptions may require revised estimate.
  • The project team will follow a hybrid delivery model using a mix of onshore and offshore resources.
  • Workflows will use out-of-the-box options, including one-step, two-step, or four-step workflows.
  • Reference data will be managed in Reference 360 through the Data Stewards interface.
  • Real-time source systems must be capable of calling MDM REST APIs.
  • Real-time target systems must expose REST APIs that MDM can call to push data. When inserting new records, the target system must synchronously return the newly generated record ID.
  • Batch source systems must provide a mechanism to identify changes since the previous extract, such as change data capture or a last-updated timestamp.
  • MDM data will be egressed as relational-style database tables for consumption by batch target systems.
  • Job orchestration will be handled through MDM Job Schedules or a third-party scheduler invoking MDM Job APIs.
  • A custom cloud application integration service for job orchestration can be provided at an additional cost.
